# 🏋️‍♂️ AI-Driven Personalized Fitness & Wellness Coach

**Your AI-powered companion for achieving your fitness and wellness goals—smarter, faster, and tailored to your needs.**

## 📘 Project Overview

In today's busy world, maintaining a healthy lifestyle can be challenging. Generic fitness plans and wellness advice often fail to address individual needs, leading to frustration and lack of progress.

**This project leverages Generative AI to create personalized fitness and wellness plans tailored to each individual's goals, preferences, and constraints.**

### 💡 What this tool does:
- Analyzes user fitness goals, current health status, and preferences.
- Generates a personalized fitness and wellness plan, including:
  - Workouts
  - Nutrition advice
  - Wellness tips (e.g., mindfulness, sleep routines)
- Adapts plans dynamically based on user feedback and progress.
- Provides actionable insights and recommendations for long-term health.

## 🌍 Real-World Use Cases

- **Health Coaches**: Use AI to assist clients with tailored fitness and nutrition advice.

## ⚙️ Setup & Dependencies

### Key Dependencies:
- **LangChain Framework**: For building AI-powered workflows.
- **ChromaDB**: Lightweight vector database for storing and retrieving embeddings.
- **Streamlit**: Interactive UI for user input and plan visualization.
- **Hugging Face Models**: For generating embeddings and natural language understanding.
- **PyPDF2**: For extracting text from fitness and nutrition PDFs.
- **YouTube Transcript API**: For processing video-based fitness tutorials.

### Installation:
```bash
# Install required Python libraries
pip install -U langchain chromadb streamlit PyPDF2 youtube-transcript-api
```

## 🛠️ How It Works

1. **User Input**: Provide your fitness goals, current health status, and preferences (e.g., workout type, dietary restrictions).
2. **AI Analysis**: The system analyzes your input and retrieves relevant fitness and wellness resources.
3. **Plan Generation**: Using Generative AI, it creates a personalized plan with:
   - Weekly workout schedules
   - Nutrition recommendations
   - Wellness tips (e.g., mindfulness exercises, sleep routines)
4. **Dynamic Updates**: Adjust the plan based on your feedback and progress.

## 🎓 Demo Example: Achieving a Balanced Lifestyle in 3 Months

### Input:
- **Goal**: Improve overall fitness and mental well-being.
- **Current Status**: Beginner, sedentary lifestyle.
- **Preferences**: Low-impact workouts, vegetarian diet.
- **Time Available**: 5 hours per week.

### Output:
#### **Personalized Plan**
1. **Week 1-4: Building Foundations**
   - **Workouts**: 3x per week (Yoga, Light Cardio)
   - **Nutrition**: High-protein vegetarian meals
   - **Wellness**: Daily mindfulness meditation (10 minutes)

2. **Week 5-8: Strength & Endurance**
   - **Workouts**: 4x per week (Bodyweight Strength, Moderate Cardio)
   - **Nutrition**: Balanced macronutrient diet
   - **Wellness**: Sleep hygiene tips (consistent bedtime)

3. **Week 9-12: Advanced Progress**
   - **Workouts**: 5x per week (HIIT, Strength Training)
   - **Nutrition**: Meal prep for sustained energy
   - **Wellness**: Journaling for mental clarity
