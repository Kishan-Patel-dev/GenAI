## 🌟 Project Overview

CardGenius is an intelligent credit card recommendation system that helps users maximize their rewards by suggesting the best card to use for each purchase. Built as a capstone project for the Google Gen AI Intensive Course, it combines Generative AI with real-time data to provide personalized card recommendations.

## 🎯 The Problem

Credit card users face several challenges:
- Multiple cards with different reward categories
- Complex point systems and rotating promotions
- Time-consuming manual comparison
- Decision fatigue for everyday purchases
- Difficulty tracking optimal card usage

## 💡 The Solution

SwipeWise addresses these challenges through:

1. **Intelligent Card Analysis**
   - Real-time reward information
   - Category-based optimization
   - Personalized recommendations
   - Justified suggestions

2. **Privacy-Focused Design**
   - No sensitive data storage
   - Card names only
   - No account numbers
   - Secure processing

3. **Real-Time Updates**
   - Live reward information
   - Current promotions
   - Seasonal offers
   - Limited-time deals
